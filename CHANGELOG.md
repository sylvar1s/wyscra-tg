# Изменения

## 0.1.0 — первый выпуск

**Bot API**
- Все 193 метода и 425 типов Bot API 10.4, сгенерированы из официальной спецификации (`npm run update-api`).
- Клавиатуры массивами, кнопки с `onClick`, удобные опции (`html`, `silent`, `replyTo`, `removeKeyboard`...).
- Команды, `hears`, `action`, фильтры `on('photo')` с сужением типов, middleware, Composer.
- `ctx.ask`, сцены (переживают перезапуск), сессии и `ctx.user` без настройки.
- Встроенная база данных: SQLite, JSON, память; PostgreSQL, MySQL, MongoDB, Redis через драйверы.
- Рассылка, статистика, админ-панель `/admin` с выгрузкой в CSV.
- Модерация групп (`ban`, `mute`, `kick`, `isAdmin`, `isSubscribed`).
- Оплата звёздами (`invoice`, `onPayment`, `refund`), inline-режим, `paginate`.
- Переводы с формами множественного числа, задачи по расписанию (every/daily/cron/once), антиспам.
- Проверка данных мини-приложений и Telegram Login Widget.
- Соблюдение лимитов Telegram, повтор при 429, кэш `file_id`, вебхуки (Node, Express, Bun, Deno, Cloudflare, Vercel).
- `npx wyscra-tg init` — создание проекта одной командой.

**MTProto**
- Клиент для юзерботов и ботов: слой 233, все 877 методов с типами.
- Вход по номеру/коду/2FA или токену бота, сессии в файле или строке.
- Переходы между DC, FLOOD_WAIT, переподключение, контроль пропущенных обновлений.
- Отправка и скачивание файлов, история, диалоги, участники.
- Обфусцированный транспорт, SOCKS5, MTProxy.
