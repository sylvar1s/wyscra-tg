# Примеры wyscra-tg

Каждый пример — готовый бот в одном файле, от простого к сложному.

## Как запустить

```bash
npm install wyscra-tg
cp .env.example .env      # впишите BOT_TOKEN от @BotFather
node 01-echo.js
```

## Список
